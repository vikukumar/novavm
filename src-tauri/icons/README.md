# NovaVM Icon Assets
#
# Place the following icon files here before building:
#   32x32.png          — Windows/Linux small icon
#   128x128.png        — Linux .deb icon
#   128x128@2x.png     — macOS Retina icon
#   icon.icns          — macOS app icon bundle
#   icon.ico           — Windows ICO (multi-size)
#
# Use tauri-icon (https://github.com/tauri-apps/tauri-icon) or
# ImageMagick to generate all sizes from a single source SVG:
#
#   npx @tauri-apps/cli icon ./assets/novavm-icon-1024.png
#
# The icon must be at least 1024×1024 pixels for best quality.
